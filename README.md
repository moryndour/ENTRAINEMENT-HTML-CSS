# Entraînement HTML / CSS · Page recette

Exercice d'intégration : reproduire une page de recette (une omelette simple) en HTML et CSS,
sans framework.

## Objectif

S'entraîner à structurer une page en HTML et à la mettre en forme en CSS :
titres, listes, blocs d'information, espacements et typographie.

## Contenu de la page

- Image d'en-tête et présentation de la recette
- Temps de préparation et de cuisson
- Liste des ingrédients et étapes de préparation
- Informations nutritionnelles

## Lancer le projet

```bash
git clone https://github.com/moryndour/ENTRAINEMENT-HTML-CSS.git
```

Puis ouvrir `entrainement/index.html` dans un navigateur.

## Structure

```text
entrainement/
├── index.html
├── style.css
└── img/image-omelette.jpeg
```

## Technologies

HTML5, CSS3.
